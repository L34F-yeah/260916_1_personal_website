## ✨ 專案特色 (Features)

- 🌊 **動態 SVG 海浪背景**：使用純 CSS 搭配 SVG 微波波浪粒子效果，營造流暢且深邃的海洋美感。
- 💎 **毛玻璃視覺設計 (Glassmorphism)**：結合 `backdrop-filter` 與精美漸變色彩，提供極具科技感的視覺體驗。
- ⏰ **即時動態時鐘**：自動顯示與更新當前日期及精確到秒的 24 小時制時間。
- 📱 **響應式設計 (Responsive Design)**：完美適配各種螢幕尺寸（桌面端、平板及行動裝置）。

---

## 🛠️ 使用技術 (Technologies Used)

- **HTML5**：語意化結構
- **CSS3**：Flexbox 佈局、CSS Keyframe 動態動畫、Glassmorphism 風格設計
- **JavaScript (ES6)**：原生 JavaScript 定時器 (`setInterval`) 即時計算與更新時間
- **Google Fonts**：使用 'Inter' 字體增强排版質感

## 🚀 本地端執行方式 (Local Setup)

1. **Clone 本專案至本地端**：
   ```bash
   git clone https://github.com/L34F-yeah/260916_1_personal_website.git
   ```
2. **開啟專案資料夾**：
   ```bash
   cd 260916_1_personal_website
   ```
3. **執行網頁**：
   直接在瀏覽器中開啟 `index.html` 即可：
   - Windows: 直接雙擊 `index.html`
   - 或使用 VS Code 的 `Live Server` 擴充功能開啟
